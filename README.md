# 🏹 Kufar Hunter Telegram Bot

Быстрый и удобный Telegram-бот для автоматического мониторинга объявлений на **Kufar.by** с мгновенными уведомлениями.

---

## ✨ Возможности

- 🎯 **Точные фильтры 1-в-1:** скопируйте ссылку с настроенными фильтрами прямо из браузера на kufar.by (категория, состояние, районы, бренд, диапазон цен) и отправьте боту.
- 🛠 **Пошаговый конструктор:** возможность настроить поиск прямо в Telegram по удобным кнопкам.
- 📸 **Галерея фотографий:** отправка объявлений полноценными фотоальбомами (до 10 фото).
- 📝 **Полная информация:** парсинг подробного описания товара, номера телефона продавца, продавца, точной локации и времени публикации.
- 🔄 **Умное распознавание обновлений:** разделение свежих объявлений и поднятых из архива / с изменённой ценой.
- 🚫 **Чёрный список («В ЧС / Не интересно»):** скрытие неподходящих объявлений в один клик прямо под объявлением, чтобы они больше никогда не появлялись.
- 📦 **Вывод всех объявлений:** просмотр актуальных предложений по активным фильтрам в любое время.
- 👤 **Мультипользовательский режим:** ботом могут пользоваться разные пользователи, каждому приходят только его уведомления.
- 👑 **Оповещения администратора:** мгновенные уведомления админу о новых пользователях и созданных ими фильтрах.
- ☁️ **Облачное сохранение данных:** автоматическая синхронизация сохранённых поисков и чёрного списка в облако Telegram (данные не сбрасываются при перезапусках и обновлениях).

## 📱 Управление и команды

| Кнопка / Команда | Описание |
|---|---|
| `➕ Добавить поиск` (`/add`) | Создать новый фильтр (по ссылке с Куфара или по кнопкам) |
| `📋 Мои поиски` (`/list`) | Список ваших активных фильтров с просмотром и удалением |
| `📦 Вывести все объявления` | Показать актуальные объявления по всем вашим фильтрам |
| `⏱ Интервал` (`/interval`) | Настройка скорости опроса сайта (15, 30, 60 или 120 сек) |
| `📊 Статистика` (`/status`) | Статистика работы (аптайм, количество поисков, ЧС, проверки) |
| `❓ Помощь` (`/help`) | Подробная инструкция по использованию |
| `/backup` | Сохранить резервную копию фильтров в Telegram |
| `/restore` | Восстановить фильтры из облачного бэкапа |

## 🚀 Быстрый запуск

У бота **нет внешних зависимостей** — он написан на стандартной библиотеке Python 3.

### 1. Клонирование репозитория
```bash
git clone https://github.com/Bernathhh/kufar-hunter-bot.git
cd kufar-hunter-bot
```

### 2. Настройка параметров
Укажите токен бота через переменные окружения или создайте `config.json` на основе `config.example.json`:

```bash
cp config.example.json config.json
```

Отредактируйте `config.json`:
```json
{
    "bot_token": "ВАШ_ТОКЕН_ОТ_BOTFATHER",
    "admin_chat_id": 123456789,
    "check_interval_seconds": 60,
    "initial_queries": []
}
```

Либо задайте переменные окружения:
- `BOT_TOKEN` — токен Telegram-бота.
- `ADMIN_CHAT_ID` — Telegram ID администратора (для получения отчётов).

### 3. Запуск

**Обычный запуск:**
```bash
python3 bot.py
```

**Запуск в Docker:**
```bash
docker compose up -d
```
